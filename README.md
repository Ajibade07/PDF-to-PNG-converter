# PDF to PNG Converter

A free Streamlit web app that converts PDF pages into PNG images.

## Features
- Upload PDF files
- Convert all pages or selected page ranges
- Choose image resolution from 72 to 600 DPI
- Preview converted images
- Download individual PNG images or all images as a ZIP file

## Run locally
Install the dependencies with `pip install -r requirements.txt` and run `streamlit run app.py`.

## Deployment
Deploy using Streamlit Community Cloud by connecting this repository and selecting `app.py` as the main file.
